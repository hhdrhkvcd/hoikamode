# Balkan Collapse — HOI4 mod

В репозитории лежит мод Hearts of Iron IV «Балканы 1980–2008: распад Югославии».

## Установка
Скопируйте папку `Balkan_Collapse` и соседний descriptor `Balkan_Collapse.mod` в пользовательскую папку `Документы/Paradox Interactive/Hearts of Iron IV/mod/`, затем активируйте мод в Paradox Launcher. Инструкция на русском есть в `Balkan_Collapse/README_RU.txt`.

Старт кампании: 1 мая 1980 года за Сербию. В моде есть распад федерации, республиканские фокусные деревья и путь к восстановлению союза. Загрузочные изображения взяты из исходного архива.
