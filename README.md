# Балканы 1980: распад Югославии (HOI4)

**Скачать мод:** [`Balkan_Collapse_1980_v3.zip`](Balkan_Collapse_1980_v3.zip). Распакуй архив и запусти `START_BALKAN.bat` (подробнее в `README_RU.txt` внутри архива).

Это самостоятельный мод. Millennium Dawn ставить не нужно: карта с реальными границами уже внутри.

## Версия 3.2 — современный арсенал Millennium Dawn

Мод вооружён по-современному: вся техника, вся наука и все армии — из Millennium Dawn.

| Что внутри | Сколько | Откуда |
|---|---|---|
| Технологии | **1487** | `common/technologies` Millennium Dawn (ветки NSB, Man the Guns, By Blood Alone, Gotterdammerung) |
| Техника и вооружение | **605** типов | `common/units/equipment`: танки, БМП, САУ, артиллерия, ПТР, ПВО, стрелковое оружие, корабли, подводные лодки, ракеты, авиация, вертолёты |
| Подразделения | **160** батальонов | `common/units`: мотострелки, мехбатальоны, танки, артиллерия, ПВО, инженеры, разведка, спецназ, десант, ВДВ, БРПЛ, авиация, флот, ракетные войска |
| Особые проекты | 8 | `common/special_projects`: бронетехника, авиация, вертолёты, ракеты, AWACS, космос, микрочипы, флот |
| Доктрины | полный набор | `common/doctrines` Millennium Dawn |

- **У всех стран современные армии.** Никакого ванильного 1936 года: каждая страна получает
  стартовый набор технологий Millennium Dawn и закрытые особые проекты (бронетехника, авиация,
  вертолёты, ракеты, AWACS, космос, микрочипы, флот). Набор технологий у каждой страны свой,
  как в Millennium Dawn: США — 409 технологий, Германия — 323, Сербия — 134, Афганистан — 30.
- **ИИ играет по-настоящему:** `common/ai_equipment` и `common/ai_templates` Millennium Dawn —
  компьютер строит дивизии из настоящих батальонов MD и закупает современную технику.
- **Югославская армия вооружена по-настоящему:** танки **M-84** и **M-84A**, БТР **BOV** и **M-60/PB**,
  БМП **BVP M-80**, РСЗ **M-77** и **M-63**, САУ **Nora B-52**; стрелковое оружие **Zastava M56, M59/66,
  M70, M70B1N, M80, M90**, зенитная **M55**, гаубицы **M48** и **M56**.
- **Авиация Югославии:** реактивные **J-22 Orao**, **G-2 Galeb**, **J-21 Jastreb**, **G-4 Super Galeb** —
  четыре авиаполка (Белград, Ниш, Сплит, Нови-Сад).
- **Флот Югославии:** корветы класса **Kotor** и подводные лодки класса **Heroj**.
- **Дивизии переделаны под MD:** мотострелковая, танковая, механизированная и пехотная бригада
  из настоящих батальонов Millennium Dawn, с инженерными и зенитными ротами.
- **Деревья фокусов теперь работают:** бонусы идут к реальным технологиям MD (доктрина
  `combined_arms`, стрелковое оружие, вычислительная техника, промышленность), а не в пустоту.

- Деревья фокусов: СФРЮ/Сербия (56 фокусов, три пути восстановления Югославии), а также Хорватия, Словения, Босния и Герцеговина, Республика Сербская, Черногория, Косово и Северная Македония.

## Сборка из исходников

```
# 1. распаковать милениум.part1.rar (нужен unrar) и Millennium Dawn с GitHub
# 2. собрать мод
python3 tools/build_mod.py --md-archive <распакованный милениум.part1.rar> \
    --md-repo <sparse checkout MillenniumDawn/Millennium-Dawn> \
    --old-mod <распакованный Balkan_Collapse_1980 (9).zip> --out build/
python3 tools/validate_mod.py build/Balkan_Collapse
# 3. собрать релиз
python3 tools/package_mod.py --build build/Balkan_Collapse \
    --old-zip Balkan_Collapse_1980_v2.zip --out Balkan_Collapse_1980_v3.zip
```

Файлы мода:

- `tools/build_mod.py` — карта, стейты, страны, флаги, локализация, портреты правителей.
- `tools/balkan_content.py` — Югославия: фокусы, события (1980–2026), идеи, закладка 1980.
- `tools/world_content.py` — три сценария, распад СССР, портреты, деревья фокусов для всех стран.
- `tools/validate_mod.py` — статические проверки (0 ошибок, 0 предупреждений).
- `tools/package_mod.py` — сборка релизного архива.
- `assets/extra_portraits/` — свои портреты правителей (подхватываются автоматически).
