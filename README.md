# Balkan Collapse — HOI4 mod

Hearts of Iron IV mod «Балканы 1980–2008: распад Югославии».

## Установка
Скопируйте папку `Balkan_Collapse` и соседний файл `Balkan_Collapse.mod` в `Документы/Paradox Interactive/Hearts of Iron IV/mod/`, затем включите мод в Paradox Launcher. Русская инструкция: `Balkan_Collapse/README_RU.txt`.

Старт: Сербия, 1 мая 1980 года. Для выбора сценария и страны установлен предоставленный фон Сербии; на загрузке показывается предоставленная композиция из исходного архива.
