# Balkan Collapse — HOI4 mod

Мод Hearts of Iron IV «Балканы 1980–2008: распад Югославии».

Для главного меню используется присланная панорама Белграда; для выбора сценария и страны — предоставленное изображение Сербии с флагом. Загрузочные экраны используют отдельные изображения из исходных материалов.

В версии 1.5 у каждого из восьми национальных деревьев — Сербии, Боснии и Герцеговины, Хорватии, Косово, Северной Македонии, Черногории, Республики Сербской и Словении — ровно 50 фокусов. Исправлены регистрации тегов, синтаксис закладки сценария и BOM в игровых текстовых файлах.

## Установка
Распакуйте весь `Balkan_Collapse_1980.zip` в отдельную папку и запустите `START_BALKAN.bat`. Скрипт ставит мод, архивирует прежний список активных модов, включает только Balkan Collapse и запускает HoI4 напрямую. Для возврата прежнего списка запустите `RESTORE_PREVIOUS_MODS.bat`. Нужен Windows и PowerShell. Подробности и ручная установка: `Balkan_Collapse/README_RU.txt`.
