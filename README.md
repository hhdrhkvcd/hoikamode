# Балканы 1980: распад Югославии (HOI4)

**Скачать мод:** [`Balkan_Collapse_1980_v2.zip`](Balkan_Collapse_1980_v2.zip). Распакуй архив и запусти `START_BALKAN.bat` (подробнее в `README_RU.txt` внутри архива).

Это самостоятельный мод. Millennium Dawn ставить не нужно: карта с реальными границами уже внутри.

![Европа, 1 мая 1980](docs/map_1980_europe.png)

## Версия 2.0
- Старт 1 мая 1980 года. Мир в границах 1980 года: СССР, ГДР/ФРГ, Чехословакия, Югославия. Закладок 1936/1939 больше нет.
- Карта, провинции и стейты взяты из Millennium Dawn (из `милениум.part*.rar`), поэтому ID стейтов совпадают с Millennium.
- Тито умирает 4 мая 1980 года, после него к власти приходит Вучич. Распад идёт по реальным датам 1990–2008, а 25.10.2026 происходит победа «Студенческого списка».
- Деревья фокусов: СФРЮ/Сербия (56 фокусов, три пути восстановления Югославии), а также Хорватия, Словения, Босния и Герцеговина, Республика Сербская, Черногория, Косово и Северная Македония (по 21 фокусу).
- У республик правители 2026 года. Загрузочные экраны: «Сербия 1980» и «Сербия».

## Сборка из исходников
```
python3 tools/build_mod.py --md-archive <распакованный милениум.part1.rar> \
    --md-repo <sparse checkout MillenniumDawn/Millennium-Dawn> \
    --old-mod <распакованный Balkan_Collapse_1980 (9).zip> --out build/
python3 tools/validate_mod.py build/Balkan_Collapse
```
