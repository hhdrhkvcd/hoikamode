# Balkan Collapse 2.0.1 — Балканы: распад и воссоединение

Самостоятельный мод для **Hearts of Iron IV** с картой из двух загруженных RAR-томов, кризисом Югославии и восстановлением федерации. **Не требует полного Millennium Dawn; вместе с ним включать нельзя.**

> **2.0.1:** убрана подмена штатного спрайта главного меню. Главное меню временно использует фон базовой игры; присланные загрузочные экраны и изображения сценариев сохранены. Это устраняет обнаруженный риск совместимости, но причина конкретного вылета без логов ещё не установлена.

## Скачать и запустить

1. Скачай **[Balkan_Collapse_1980.zip](Balkan_Collapse_1980.zip)** из этой версии репозитория. Внутри должна быть версия **2.0.1**, а не старый ZIP 1.6.
2. Распакуй **весь архив** в отдельную папку. Не запускай BAT из окна архиватора.
3. Закрой HOI4 и Paradox Launcher. Запусти **`START_BALKAN.bat`**, подтверди `Y`.
4. Начни **новую игру** и выбери **1980** или **2008**. Старые сохранения этой карты несовместимы.

Установщик сохраняет прежнюю версию мода и список активных модов, включает только Balkan Collapse, сохраняет выбор DLC и пробует запустить `hoi4.exe` напрямую с `-debug`. Он не удаляет сохранения, настройки или файлы игры. Если игра установлена не в найденной библиотеке Steam, можно указать путь:

```powershell
.\START_BALKAN.ps1 -GamePath "D:\SteamLibrary\steamapps\common\Hearts of Iron IV\hoi4.exe"
```

**Если сама HOI4 сейчас не открывается:** `START_VANILLA.bat` временно отключает все моды, не удаляя их. `RESTORE_PREVIOUS_MODS.bat` возвращает последний сохранённый список — вместе с прежними модами из него. Если чистая игра тоже не запускается, проблема не обязательно в Balkan Collapse: проверь целостность игры в Steam.

**При вылете:** запусти `COLLECT_BALKAN_LOGS.bat` и пришли ZIP из `diagnostics/`, версию HOI4 и выбранный сценарий. Перед отправкой просмотри логи: в них могут быть имя пользователя Windows, пути и сведения о компьютере. Сохранения и дампы памяти не собираются.

## Что внутри

| Старт | Содержание |
|---|---|
| **1 мая 1980** | Единая Югославия под Тито, экономический кризис; смерть Тито 4 мая и переход к Вучичу по альтернативному лору. Выход республик развивается в 1991–2008 годах. |
| **18 февраля 2008** | Быстрый старт после распада: Сербия, Хорватия, Словения, Босния и Герцеговина, Республика Сербская, Черногория, Северная Македония и Косово доступны для выбора. |

- **8 национальных деревьев по 50 фокусов**: экономика, армия, дипломатия, независимость и объединение. Есть заводы, инфраструктура, оборудование и исследовательские бонусы, а не только очки политики.
- У Сербии — взаимоисключающие дипломатический и военный пути. Мирное объединение требует согласия республик. Отказ сохраняет их независимость; повторные переговоры доступны через решения.
- Военный фокус открывает цели и **отдельные решения об объявлении войны**. Семь войн автоматически не начинаются.
- Восстановление требует владеть и полностью контролировать **все 20 областей** бывшей федерации. После восстановления обязательные выходы республик прекращаются.
- **1 493 области, 224 стратегических региона**, согласованные провинции, столицы, железные дороги и узлы снабжения из присланной карты. Старые номера областей не смешиваются с новой картой.
- Фоны, загрузочные экраны и значки фокусов используют **присланные изображения**. Новые фотографии нейросетью не создавались. У Тито вырезанный портрет из присланной иллюстрации; для остальных лидеров пока используются честные символические панели с флагами, а не выдуманные фотографии этих людей.

## Важные границы проекта

Это **альтернативная история**, а не утверждение, что Вучич действительно был преемником Тито. Политический состав 2026 года намеренно перенесён в более ранние даты. Республика Сербская представлена отдельным игровым субъектом Боснии и Герцеговины после Дейтона; статус Косово отмечен как спорный.

Из архивов перенесена и адаптирована **карта**, а не вся механика Millennium Dawn. Особые типы местности и здания, для которых не было определений, заменены/исключены. Технологии и основные системы — базовой HOI4; остальные страны мира упрощены и наследуют расстановку из присланных материалов. Это не полная историческая реконструкция всего мира 1980 или 2026 года.

**Проверены файлы, ссылки, геометрия карты и модель цепочки событий. Запуск настоящей HOI4 здесь не проверен; совместимость с твоей конкретной версией нужно подтвердить в игре.** Инструкция проверки: [docs/TESTING_RU.md](docs/TESTING_RU.md).

## Если скачал исходники GitHub, а не установочный ZIP

В Git большие изображения карты хранятся один раз в `assets/millennium_map.zip`. `START_BALKAN.bat` сам распакует их в устанавливаемую копию. Просто скопировать исходную папку `Balkan_Collapse` без распаковки карты **недостаточно**.

Для готового ZIP достаточно Python 3.10+; сторонние пакеты и распаковщик RAR не нужны:

```bash
python tools/build_mod.py
```

Проверки разработки:

```bash
python -m pip install -r requirements-dev.txt
python -m pytest -q
python tools/validate_mod.py --deep-images --package Balkan_Collapse_1980.zip
```

Подробности: [изменения](docs/CHANGES_RU.md), [происхождение материалов](NOTICE.md), [повторный импорт карты](docs/DEVELOPMENT.md). Использованная картинка из старого Recovery-архива отдельно сохранена в `assets/source/`; сам старый архив не возвращается после удаления в `main`. Старые ZIP, включая `Balkan_Collapse_1980 (9).zip` версии 1.5, **не являются рекомендуемой сборкой для установки**.
