# Balkan Collapse — HOI4 mod

Мод Hearts of Iron IV «Балканы 1980–2008: распад Югославии».

Для главного меню используется присланная панорама Белграда; для выбора сценария и страны — предоставленное изображение Сербии с флагом. Загрузочные экраны используют отдельные изображения из исходных материалов.

## Установка
Распакуйте `Balkan_Collapse_1980.zip` в `Документы/Paradox Interactive/Hearts of Iron IV/mod/`. Рядом должны находиться папка `Balkan_Collapse` и файл `Balkan_Collapse.mod`. Для первой проверки включите в отдельном плейсете только этот мод. Подробная инструкция: `Balkan_Collapse/README_RU.txt`.
